# AI-Powered College Complaint Automation

An automated college complaint management system built using n8n.

## Features

- Google Sheets complaint trigger
- AI-based complaint analysis
- Automatic department classification
- Complaint category classification
- Priority detection
- Complaint summary generation
- Recommended action generation
- Automatic result storage in Google Sheets

## Workflow

Google Sheets
↓
n8n
↓
AI / Gemini
↓
Complaint Classification
↓
Department + Category + Priority
↓
Google Sheets

## Technologies

- n8n
- Google Sheets
- Gemini AI
- Automation
- JSON

## Use Case

This system helps colleges automatically analyze student complaints and organize them for faster administration.
